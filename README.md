# SkillSwap
SkillSwap is a full-stack web application where users can **teach their skills and learn new skills from other users**.

## Features

* User Registration and Login
* JWT Authentication
* User Profile
* Add skills to teach
* Add skills to learn
* Explore users by skills
* Send skill exchange requests
* Accept or reject requests
* Chat with other users
* Protected Routes
* Responsive Design
